# smol/static-nojs-v1

`smol/static-nojs-v1` is the output profile for self-contained static pages
generated by `smol`.

The canonical profile identifier is `smol/static-nojs-v1`. Filesystem paths may
use hyphens for convenience, but the slash form is the profile name emitted in
the signed manifest.

## Signing Model

In v1, attestation is whole-page only. When signing is enabled, `smol` renders a
complete HTML page, then calls `attest` / `attested-html` as the final build
step. The signed payload is the full generated HTML byte string handled by the
signer.

Structural regions described by this profile are provenance and diff aids. They
are not independent signatures. Changing generated navigation or theme chrome
changes the signed page payload.

Gemini capsule output is unsigned in v1.

## Static Policy

Generated HTML is expected to remain script-free and self-contained:

- inline CSS only;
- local supported images embedded as `data:` URLs;
- XHTML-style static markup discipline.

The static validator rejects JavaScript, `javascript:` URLs, event-handler
attributes, refresh meta tags, external stylesheet/preload/resource links,
non-embedded images, external media, iframes, objects, embeds, forms, buttons,
textareas, and selects.

Nested/default HTML also rejects inline SVG and all `<input>` elements.
`flat-xhtml-v1` permits inline SVG and the canonical static checkbox inputs
used by task-list rendering.

Strict historical XHTML DTD conformance is not a goal. `smol` uses XHTML-style
output for consistent closing and static markup, not for DTD purity.

## Structural Regions

Regions are a vocabulary for understanding generated output. Current emitted
HTML only marks authored content and generated navigation when page navigation
exists.

### Page Top Anchor

When `.PageNav.HasLinks` is true in the starter themes, the page body is:

```html
<body id="top">
```

The `id` exists only to support the generated HTML-only `Top` navigation link.
When no page navigation is generated, the starter themes do not add this anchor.

### Authored Content

Authored content is HTML derived from the page body source: `body.html`,
`body.md`, or `body.gmi` rendered to HTML.

When `.PageNav.HasLinks` is true in the starter themes, authored content is
inside:

```html
<main id="content" data-smol-authored-content="true">
```

When no page navigation is generated, the starter themes do not add this marker
so link-less output remains byte-stable.

### Generated Navigation

Generated navigation is navigation synthesized from `page.json` `links`, page
titles, and output routing.

In HTML starter output, generated navigation is:

```html
<nav data-smol-generated-chrome="navigation" aria-label="Page navigation">
```

This region can include synthesized links in addition to author-declared
targets:

- `Top`, an HTML-only `#top` link;
- `Home`, when an `index` page exists and the source page is not `index`;
- `Up`, `Previous`, `Next`, and `Related` links from `page.json`.

The emitted attribute names this as navigation-flavored generated chrome. It is
not a separately signed region.

### Chrome

Chrome is theme-generated page shell outside authored content and generated
navigation, such as headers, footers, inline CSS, site navigation, and template
structure.

Chrome is implicit in v1. The starter themes do not emit a dedicated
`data-smol-region="chrome"` marker.

## Gemini Equivalence

Gemini output has no HTML attributes. For `flat-gemini-v1`, generated page
navigation is represented as a trailing block of `=>` link lines after the
rendered body.

The HTML-only `Top` link is not emitted in Gemini.

## Manifest

Nested HTML output includes a `SMOL ATTESTED MANIFEST V1` comment. The manifest
is covered by the whole-page signature only when signing is enabled. Flat XHTML
and Gemini outputs do not carry an embedded manifest today.

See `docs/smol-attested-manifest-v1.md` for the manifest format.
